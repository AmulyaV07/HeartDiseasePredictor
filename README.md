
# ❤️ Heart Disease Prediction using Machine Learning

An educational machine learning project that predicts the heart disease class using a K-Nearest Neighbors (KNN) classifier.

## Features
- Data preprocessing
- One-Hot Encoding
- Feature scaling with StandardScaler
- Comparison of five classification algorithms
- Cross-validation using F1 score
- Interactive Streamlit frontend

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit

## Run Locally
Install dependencies:

pip install -r requirements.txt

Start the app:

streamlit run app.py

## Disclaimer
This project is for educational purposes only.
It is not a medically validated diagnostic tool.
